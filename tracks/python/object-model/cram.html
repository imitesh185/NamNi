Object Model 1.1–1.3 · CRAM

1 · The chant

Five lines. Say them until they are reflex. Every other page is a consequence.

  1. A name is a key, not a box.Binding inserts a key. It never copies the object.
  2. A container holds references, not objects.Name · index · key · attribute = one mechanism, four key types.
  3. = changes a slot. A method changes the object.Rebind vs mutate. This is 80% of every trap.
  4. Shared + mutated = visible. Everything else is private.Two questions only: is it shared, and did you mutate it?
  5. Nothing is copied unless you ask — and then only one level.Slice, list(), copy() are all the same shallow copy.

3 · Why-cards — answer aloud, then click

Knowing the output is not knowing. Mark ✗ wrong on any you fumble — they collect below and survive a reload.

CORE
What is the difference between nums[0] = 9 and nums[0].append(9)?
First overwrites the pointer stored in slot 0. Second follows that pointer and changes the object. Only the second is visible through other references.✗ wrong
CORE
Does an object's address ever change?
Never. An object sits at one address for its whole life. Only which pointer a slot holds changes. "The id changed" always means "a different object is there now".✗ wrong
1.1
When is it safe to compare with is?
Singletons only — None, True, False, your own sentinels. is asks identity and cannot be overridden; == calls __eq__.✗ wrong
1.1
Two objects show the same id(). What can you conclude?
Nothing, unless both are alive at the same time. Dead objects' addresses are reused instantly. Never cache or compare ids across time.✗ wrong
1.2
TypeError: 'list' object is not callable — first thing you check?
You shadowed the builtin: somewhere list = [...]. Builtins are searched last (L→E→G→B), so any earlier binding wins. Fix: del list.✗ wrong
1.2
Does del x free memory?
No. It removes a binding. The object dies only when its last reference goes. del is a namespace operation.✗ wrong
1.3
m is t is False but every element id matches. Which copy is it?
Shallow. New outer object, same element pointers. Matching element ids is the proof of shallowness, not evidence of aliasing.✗ wrong
1.3
Two booleans that fully identify copy depth?
b is a and b[0] is a[0]. True/True = alias. False/True = shallow. False/False = deep.✗ wrong
1.3
Why does deepcopy return the same int / str object?
Deep copy exists to stop mutation leaking. Immutables can't be mutated, so a copy is indistinguishable from the original. True at any size — not just cached small ints.✗ wrong
1.3
Why is [0]*3 "fine" but [[]]*3 "broken"?
Neither is broken — both share one object three times. int has no mutating method, so the sharing is unobservable. The rule never changed; mutability revealed it.✗ wrong
1.3
Explain the += tuple paradox in 3 steps.
1) load t[0] · 2) __iadd__ mutates the list in place — commits · 3) store back into the tuple — fails, TypeError. Mutation already happened.✗ wrong
1.3
Is Python pass-by-value or pass-by-reference?
Neither — don't use the phrase. Parameters are bindings in a new namespace. Mutation is visible to the caller, rebinding is not. Same rule as everywhere else.✗ wrong
1.3
Why does bucket=[] accumulate across calls?
The default is evaluated once, at def time, and stored in f.__defaults__. Every call rebinds the same object. Fix: =None sentinel.✗ wrong
1.3
Safe copy of {"hosts": ["a","b"]} for untrusted code — which depth?
Deep. Shallow gives a new dict but the same inner list, so they can still mutate your data through it. Deep only works if you own the whole graph.✗ wrong
TRAP
A comprehension leaks its variable — true or false?
False. Comprehensions get their own scope. for loops do not — the loop variable survives after the loop.✗ wrong
TRAP
Why does a bare class attribute name fail inside a method?
A class body is a namespace but not an enclosing scope. LEGB skips it. Use self.x or C.x.✗ wrong

    4 · Kill list

    Six habits. Each one is a bug you will otherwise ship.

    NEVER [[...]] * nUse [... for _ in range(n)]. Always.
    NEVER a mutable default=None, then build inside.
    NEVER shadow a builtinlist dict str id type len.
    NEVER trust "a copy"Ask: shallow or deep? Check b[0] is a[0].
    NEVER cache id()Addresses are recycled the moment an object dies.
    NEVER say by-value / by-referenceSay: rebinding vs mutation.

    6 · Know it exists — recognise, don't memorise

    • LEGB — Local → Enclosing → Global → Builtins, first hit wins. Scope = search order, not memory.
    • except … as e deletes e at block exit. Copy it out first.
    • globals() is live; locals() is a snapshot — writing to it does nothing. [CPython]
    • type(x) reads the header and cannot lie; __class__ is an ordinary attribute and can.
    • Types are objects; type(type) is type. Small ints and interned strings are cached. [CPython]
