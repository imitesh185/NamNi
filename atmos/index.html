Atmos

Engineering notes in two states. Reference collections compress the Forge into visual mechanisms. Field notes close one of those mechanisms only after a written prediction meets a measured system.

The governing distinction. A source-grounded reference may explain how a system is expected to behave. It must never claim that you observed that behavior. Only rerun and ablation evidence can close a field note. Reference is a model; experiment turns it into evidence.

01 The two passes

One investigation, one evolving artifact, two evidence gates.

ModeRequired evidenceProducesMust not claim
GateBaseline inputs incompleteSmallest experiment and what to recordThe mechanism or expected answer
Pass 1Prediction, falsifier, actual baseline result, wrong assumptionFailure reconstruction, minimum mechanism, repair testThat repair or ablation succeeded
Pass 2Actual modification, rerun metrics, ablation metricsRevised model, causal claim, reconstruction and transferMore certainty than the evidence supports
One failure, not one node The laboratory is the experimental unit. A single failure may demand several connected concepts, so one note may integrate several source nodes. No new lab is invented merely because a node exists.

02 Evidence discipline

The note preserves the line between measurement and explanation.

LabelPermitted meaning
[OBSERVED]Present in supplied output, metrics, plans, logs, traces, or file state.
[PREDICTED]Committed before the run whose result it predicts.
[INFERRED]A causal interpretation supported by evidence but not directly measured.
[UNKNOWN]Not established; either test next or park as concept debt.
